# AGENTS.md

## Scope

- Это локальное Chrome-расширение для `https://odnotomnik.ru/profile/orders`.
- Для маленькой задачи делайте маленькое изменение; не рефакторьте соседний код без необходимости.

## Invariants

- Не отправляйте данные заказов, клиентов или доставок во внешние сервисы.
- Не меняйте заказы, оплату и данные аккаунта: расширение только читает DOM и меняет представление в браузере.
- Используйте штатное действие «Подробнее» для данных, отсутствующих в таблице; не создавайте отдельный сетевой клиент без необходимости.

## Boundaries

- `src/content.js` выполняется в content-script isolated world. Доступ к данным заказа строится через DOM и `#order-view-modal`, а не вызовом функций сайта напрямую.
- Селекторы сайта могут меняться: перед их изменением проверьте фактическую DOM-разметку страницы.

## Checks

- После изменения `manifest.json` проверьте его через `ConvertFrom-Json`.
- После изменения UI проверьте страницу заказов вручную в Chrome; укажите фактически выполненные проверки и важные пропущенные.
