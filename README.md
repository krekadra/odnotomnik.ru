# Однотомник — удобные заказы

Chrome-расширение для страниц заказов, корзины и редактора макетов на `odnotomnik.ru`. Оно не меняет сайт: на стороне браузера заменяет перегруженные таблицы на карточки с характеристиками печати и компактные строки книг.

## Состояние

Расширение обрабатывает `https://odnotomnik.ru/profile/orders`, `https://odnotomnik.ru/shopcart` и страницы `/photobook/designer/edit/*`. На заказах детали загружаются в фоне через штатное «Подробнее»; в корзине параметры берутся из уже присутствующего tooltip. В редакторе книги собраны в горизонтальные строки, успешные проверки скрыты, а ошибки остаются заметными.

## Структура

- `manifest.json` — манифест Chrome Manifest V3.
- `src/content.js` — преобразование таблицы и разбор окна заказа.
- `src/content.css` — изолированные стили нового интерфейса.

## Запуск

Расширение не требует сборки.

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите корень этого репозитория.
4. Откройте или обновите страницу заказов на `odnotomnik.ru`.

## Проверки

Проверить JSON-манифест:

```powershell
Get-Content manifest.json -Raw | ConvertFrom-Json | Out-Null
```

Проверка интерфейса: открыть страницу заказов в Chrome и убедиться, что карточки появляются сразу, а блок «В печати» заполняется после загрузки спецификаций.

## Приватность

Расширение работает только на странице заказов Однотомника, не отправляет данные на внешние сервисы и не меняет заказы.
