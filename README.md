# Однотомник — удобные заказы

Локальное Chrome-расширение для сотрудников/пользователей `odnotomnik.ru`, работающих с заказами фотокниг. Оно только меняет представление уже открытых страниц: превращает таблицу заказов и корзину в компактные карточки, а в редакторе фотокниги упорядочивает параметры и макеты. Результат — быстрее читаемые сведения о печати без изменения заказов, оплаты или данных аккаунта.

Перед работой прочитайте [AGENTS.md](AGENTS.md): там закреплены границы доступа к данным и правила работы с DOM сайта.

## Текущее состояние

Реализованный и активный runtime — единственное Chrome Manifest V3-расширение в этом репозитории. Оно подключается к трём типам страниц:

- `/profile/orders` — заменяет таблицу заказов карточками; спецификации получает через штатное действие «Подробнее» и DOM модального окна.
- `/shopcart` — показывает параметры уже находящихся в корзине фотокниг в карточках.
- `/photobook/designer/edit/*` — упорядочивает настройки тиража и превью разворотов редактора.

Отдельных legacy-, experimental- или roadmap-каталогов, а также отдельного current/status-документа в репозитории нет. Не считайте описанную выше функциональность планом: она реализована в `src/content.js`.

## Карта системы и runtime

| Часть | Назначение / точка входа |
| --- | --- |
| `manifest.json` | Нормативная конфигурация Manifest V3: URL-матчи, подключаемые JS и CSS, момент запуска. |
| `src/content.js` | Единственный content script и основной runtime. Внизу файла выбирает обработчик по `location.pathname`; здесь же DOM-разбор, рендеринг и наблюдатели. |
| `src/content.css` | Стили карточек заказов и корзины, а также доработок редактора. |

Расширение не имеет backend, сетевого клиента, хранилища, сборочного контура или generated-артефактов. Оно использует DOM уже загруженных страниц; для деталей заказа нажимает существующую ссылку «Подробнее» и читает `#order-view-modal`.

## Куда смотреть

| Если задача про | Начать с |

| подключение расширения, URL или права | `manifest.json` |

## Sources of truth

## Локальный запуск

Сборка не требуется.

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите корень репозитория.
4. Откройте или обновите одну из поддерживаемых страниц `odnotomnik.ru`.

## Проверки

Минимальная проверка после изменения манифеста:

```powershell
Get-Content manifest.json -Raw | ConvertFrom-Json | Out-Null
```

Проверка UI — вручную в Chrome на затронутой странице. Для заказов убедитесь, что карточки появляются и блок «В печати» заполняется после загрузки спецификаций; для корзины и редактора проверьте соответствующий изменённый сценарий. Автоматических тестов, CI и отдельного release-checkpoint в репозитории нет.
